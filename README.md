# dxweb2
DX Web ページのデザインアレンジ集

基本形（合同会社two verse トップページ）をもとに、ボタンの位置・形・動きやレイアウトをアレンジしたパターンです。文章と構成は共通です。ビジネス向けに、濃い色の帯や太い見出しでメリハリをつけています。ページ全体は「静」で、ボタンやカードは動かさず、写真だけがゆっくり動きます。色違いは [dxweb](https://github.com/hhoshizora-usagi/dxweb) にあります。

| No. | デザイン | 配色 | ポイント | ファイル |
|--|--|--|--|--|
| 01 | センターヒーロー | ネイビー × ゴールド | 写真をヒーロー全面に敷いて、見出しとボタンを中央にそろえた形。写真はゆっくりズーム／ボタンは角丸小さめ。ふれると色だけ静かに変わる／ヘッダーの「お問い合わせ」は線だけのボタン／カードはふれると上にアクセントの線／導入の流れのセクションを濃い色の帯にしてメリハリ | [01-center/index.html](01-center/index.html) |
| 02 | フローティング | インディゴ × コーラル | ヘッダーが浮かぶカプセル型／写真の上に文章カードを重ねた形。写真はゆっくりズーム／ボタンは丸い矢印つき。ふれると矢印がすっと右へ／スクロールすると右下に「お問い合わせ」ボタンが追従／学習基盤のセクションを濃い色の帯にしてメリハリ | [02-floating/index.html](02-floating/index.html) |
| 03 | シャープブロック | チャコール × オレンジ | 角のない四角いブロックで統一／ボタンはくっきりした影つきで、動かさずどっしり／写真は横にめくれるように切りかわる／カードやプログラムも太い線と影で強めに／見出しの下に太いアクセントのバー | [03-sharp/index.html](03-sharp/index.html) |
| 04 | ライト＆ライン | エバーグリーン × マスタード（基本形の色） | ヒーローを白背景にして、写真は角丸の枠に／メインのボタンは左から色が満ちる動き／サブのボタンは下線つきの文字リンク／スマホでは画面下に「お問い合わせ」バーが固定／会社紹介のセクションを濃い色の帯にしてメリハリ | [04-light-line/index.html](04-light-line/index.html) |

## しくみ
- `index.html` … 全パターンの一覧ページ
- `assets/style.css` … 全パターン共通の土台（基本形のデザイン）
- `assets/v01.css` 〜 `assets/v04.css` … パターンごとのアレンジ（ボタンの形・動き・レイアウト・メリハリの上書き）
- 静と動 … ボタンやカードは動かさず、写真だけを動かしています（ヒーロー写真のゆっくりズーム、カードやプログラムの写真はふれると少しズーム、お問い合わせ帯の写真がゆっくり流れる）。
- `assets/main.js` … スライドショー・スマホメニュー・ページ上部へ戻るボタン・追従する相談ボタン
- 各フォルダの `index.html` … 先頭の `:root{ ... }` が色、読みこむ `assets/vXX.css` がデザインです。組み合わせを入れかえると、別の色×デザインも作れます。
