# dxweb2
DX Web ページのデザインアレンジ集

基本形（合同会社two verse トップページ）をもとに、ボタンの位置・形・動きやレイアウトをアレンジしたパターンです。文章と構成は共通です。ビジネス向けに、濃い色の帯や太い見出しでメリハリをつけています。ページ全体は「静」で、ボタンやカードは動かさず、写真だけがゆっくり動きます。色違いは [dxweb](https://github.com/hhoshizora-usagi/dxweb) にあります。

## しくみ
- `index.html` … 全パターンの一覧ページ
- `assets/style.css` … 全パターン共通の土台（基本形のデザイン）
- `assets/v01.css` 〜 `assets/v08.css` … パターンごとのアレンジ（ボタンの形・動き・レイアウト・メリハリの上書き）
- 静と動 … ボタンやカードは動かさず、写真だけを動かしています（ヒーロー写真のゆっくりズーム、カードやプログラムの写真はふれると少しズーム、お問い合わせ帯の写真がゆっくり流れる）。
- `assets/main.js` … スライドショー・スマホメニュー・ページ上部へ戻るボタン・追従する相談ボタン
- 各フォルダの `index.html` … 先頭の `:root{ ... }` が色、読みこむ `assets/vXX.css` がデザインです。組み合わせを入れかえると、別の色×デザインも作れます。
